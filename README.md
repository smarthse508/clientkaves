Jika kalian menggunakan library tambahan jangan lupa untuk mengedit README.md ini agar teman-teman yang lain bisa ter-update

# Cara menjalankan project ini di lokal

1. Setelah kamu clone, cek apakah package.json sudah ada atau belum. Jika belum => npm install
2. Jika sudah ada, jalankan project dengan perintah npm run dev
3. Karena animasi pada halaman memakai library dari framer motion, jangan lupa diinstall juga dengan cara => npm install framer-motion
